# Cross-system gap audit prompt

Audit the implemented system for unhandled lifecycle and cross-module cases. Do not add features yet.

Trace at least: orphaned dependent; last specialist dies; settlement loses water/food; route closes mid-journey; destination fills during migration; pregnancy spans migration/disaster; epidemic plus conflict; employer/owner/government dissolves; currency/market becomes unusable; technology exists without materials/skills/infrastructure; knowledge is lost; projection consumer replays duplicates/out of order; content version changes during queued work; clock lease changes during commit; subscriber target spikes/drops/goes stale; AI source contains prompt injection; archive claims unsupported causality; backup restore resumes mid-season.

For each gap, cite current behavior/tests or mark it missing; rank consequence/likelihood; propose the smallest contract/test/implementation change and owning phase. Distinguish intentional abstraction from bug. Output a prioritized audit document, not code.
