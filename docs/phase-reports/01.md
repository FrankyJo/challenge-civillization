## Compatibility, migrations, rollout and rollback

**Database:** no migration; the schema is unchanged.

**Wire changes to existing endpoints:**
- The API's 404 body changed from Fastify's default to `ApiError`.
- The health servers' 404, 405 and 500 bodies changed from `{error}` to `ApiError`.
- `health-report` now strips unknown fields when read; it previously did too, so this is unchanged.
- No external consumers exist yet. The web shell reads only `/health/ready`, whose shape is unchanged.

**Contracts:** all at v1. The fixtures freeze them, so future changes must follow the versioned policy.

**Rollback:** revert the Phase 01 commit. No persisted data depends on it.

**Deployment:** none performed or authorized. No subscriber data is touched.
